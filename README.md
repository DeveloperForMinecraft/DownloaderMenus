## Usage
### Download
- Download Minecraft Forge
- Download Mod: <a href="https://github.com/DecentMCDev/DownloaderMenus/releases/download/Release/DownloaderMenus.jar" class="custom-cursor-on-hover">DownloaderMenus.jar</a>
- Copy the downloaded file to your `.minecraft/mods/` root folder.
- Run minecraft on version 1.16.5
- Connect any server and open any menu
- Click on button "Скачать Меню"
- Check your local `.minecraft/Downloaded Menus/ip of server/` folder (or the path shown in the chat) — the downloaded menu file will be there.

### Building
- Clone this repository
- Run `./gradlew build`
