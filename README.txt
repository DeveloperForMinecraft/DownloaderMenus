***DownloaderMenus***

This client-side mod allows players to download menu configuration files directly from the server.
It is designed to work with the "DeluxeMenus" plugin. When any chest GUI menu is opened, a "Скачать Меню" button appears in the top-left corner of the screen.
Clicking this button saves the current menu's configuration file to the player's computer and sends a chat message confirming the download location and filename.
